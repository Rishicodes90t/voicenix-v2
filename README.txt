PUBLISH ON GITHUB PAGES
Upload the CONTENTS of this folder to your repository root (all six .html files, styles.css, script.js, assets/).
Settings > Pages > Deploy from a branch > main > /(root).
Local preview: python -m http.server 8000

BEFORE PUBLISHING
- Replace https://YOUR-DOMAIN-HERE in the canonical tag of each page with your real site URL.
- Check the map pin on contact.html and studio.html. If Google places it slightly off, replace the iframe src with Share > Embed a map for your exact listing.
- Confirm the languages, deliverables, discount terms and talent availability match what the studio really offers.
- Audio files are synthetic interface demos and portfolio titles are concepts. Replace with approved studio work when available.
